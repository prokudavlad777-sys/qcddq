# AirDrop (Paper 26.3)

Аирдропы: груз падает с неба каждые 30 минут или по команде. Сообщения на русском.

## Команды (право `airdrop.admin`, по умолчанию op)
- `/drop` — сбросить аирдроп в случайной точке
- `/drop here` — сбросить над своей позицией
- `/drop reload` — перезагрузить config.yml и таймер

## Как работает
- Груз падает с высоты 100 блоков (светящийся сундук с дымом), приземляется и превращается в большой сундук 9x6.
- Лут сундука задан в `config.yml` (секция `loot`, слоты 0-53 сверху вниз по рядам) — повторяет скриншот.
- Сундук нельзя сломать и взорвать. Исчезает, когда его полностью опустошили, или через `lifetime-minutes`.
- Интервал, радиус, высота падения, лимит активных дропов и все тексты — в `config.yml`.

## Сборка
GitHub → Actions → Build → Artifacts → `AirDrop.jar`.
